# Space Speller (Космическая Азбука) 🚀

**Space Speller** — это увлекательная обучающая веб-игра для детей, которая помогает развивать навыки чтения и быстрого набора букв на клавиатуре.

🎮 **[ИГРАТЬ ПРЯМО СЕЙЧАС](https://even-hen.github.io/Space-Speller/)**

## Особенности
* **Защита Земли:** Ребенок управляет космическим кораблем и должен сбивать падающие объекты (астероиды, пришельцы, мультяшные планеты), правильно набирая буквы.
* **Голосовая озвучка:** Все слова, которые необходимо набрать, произносятся вслух (Text-to-Speech) для развития слухового восприятия.
* **Три уникальных визуальных стиля:**
  * 🌌 **Неон** — стильный киберпанк (тема по умолчанию).
  * 📟 **Ретро** — олдскульный пиксель-арт с классическими космическими захватчиками.
  * 🧸 **Мультик** — яркий, добрый и мягкий стиль.
* **Несколько уровней сложности:** Настройка длины слов и скорости падения объектов.
* **Два режима игры:** Практика (без потери жизней) и Аркада (на рекорд с жизнями).
* **Поддержка любых устройств:** Игра полноценно работает как на десктопе (через физическую клавиатуру), так и в мобильных браузерах (со встроенной удобной экранной клавиатурой).

## Как запустить
Просто откройте игру в любом современном браузере по ссылке: 
[https://even-hen.github.io/Space-Speller/](https://even-hen.github.io/Space-Speller/)
Выбирайте уровень, стиль и жмите «СТАРТ»!
